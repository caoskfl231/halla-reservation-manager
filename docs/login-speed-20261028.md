# 로그인 대기 개선 (2026-10-28)

로그인 권한 확인은 기존 halla_ledger_sync_v2(p_cursor:null) 목록 응답으로 수행한다. 이 RPC는 기존 회원·MFA 검증을 거치며 로그인 중 전체 거래내역을 내려받지 않는다. 이동한 장부 화면의 기존 자료 조회는 유지한다.

자동 로그인도 같은 권한 검증을 거친다. 중복 로그인 제출을 차단하고, 비밀번호 인증 성공 뒤 자료 조회/연결 실패는 세션을 보존한 채 명시적 재시도를 제공한다. 잘못된 TOTP 오류는 한국어로 안내한다.

캐시 갱신은 login.html의 로그인 스크립트 URL에만 적용했다. 장부 데이터·계정·비밀번호·MFA 설정·DB 스키마 변경 없음. 업무명령 개발 브랜치 변경은 포함하지 않는다.

검증: node --experimental-vm-modules --test tests/*.test.cjs (53개 통과), 자산 버전 참조 검사 통과. 실제 기기에서의 인증 대기 시간은 사용자 확인이 필요하다.
